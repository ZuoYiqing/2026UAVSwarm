# JEPA 首轮实验与离线迁移记录（2026-10-09）

## 当前结论

已完成独立的 **4,491 参数状态 JEPA 原型**训练、评估与纯 Python 推理包。
这是我们自己实现的简化研究实验，不是下载并运行了官方 SkyJEPA，也不是视觉
JEPA：输入是位置/速度历史和候选加速度，输出是未来位置/速度预测。
不能把它称为无人机动力学模型、避障能力、巡检完成判据或飞行控制器。

成果位于原算法 worktree 的 `algorithm_lab/world_model_lab/`。开发时工作区从本地
main 快进至 `8806f94`；没有修改 Runtime/前端/仿真代码，没有启动其他模块，
没有发送设备动作。本文随源码进入版本控制，实际提交和合并状态以 Git 为准。

## 实验方法与可追溯文件

训练环境：Windows AMD64、Python 3.11.7、PyTorch 2.2.2+cu121、NumPy 1.26.4。
本轮实际用 **CPU 单线程训练**，不是 RTX 4050 推理或训练，也不是 Orin 实测。
使用已有 D 盘 Python 环境，未安装包、未改根依赖。最终复跑仅在子进程设置
`OMP_NUM_THREADS=1`、`MKL_NUM_THREADS=1`，不修改系统环境变量。

模拟对象是带执行器滞后、阻力和恒定风的三维点质量；dt=0.1 秒，历史 8 帧，
预测 10 帧（1 秒）。没有姿态、角速度、旋翼输入、传感器噪声或碰撞。
训练/验证/测试数据 seed=101/202/303，分别 32/8/16 条独立轨迹，各 7 个窗口，
总计 224/56/112 窗口。整条轨迹和其物理参数只在一个 split 中，不随机拆帧。
参数域来自同一个分布，**不是分布外泛化验证**；测试窗口也不全是独立样本。

模型种子 11/23/37；每轮潜空间训练 40 epoch、冻结编码器/预测器后的探针训练
60 epoch。最优 epoch 仅按验证集选择，三轮都评估同一份测试集。打包采用事先
固定的 seed=11，不按测试成绩挑选种子。

| 种子 | 潜空间/探针选中 epoch | 1 秒位置 RMSE（m） | 训练及评估耗时（s） |
| --- | --- | --- | --- |
| 11 | 40 / 53 | 0.120365 | 11.224 |
| 23 | 30 / 60 | 0.121094 | 11.092 |
| 37 | 38 / 57 | 0.128319 | 11.655 |

三种子位置 RMSE 均值 0.123259 m、样本标准差 0.004397 m。这只是本配置的
描述性结果，不是显著性检验或真实飞行精度。

| 方法 | 0.1 秒位置 RMSE（m） | 0.5 秒位置 RMSE（m） | 1 秒位置 RMSE（m） |
| --- | --- | --- | --- |
| 匀速 | 0.005395 | 0.134313 | 0.524865 |
| 名义加速度积分 | 0.001951 | 0.048197 | 0.187036 |
| 训练集拟合的线性残差 | 0.000417 | 0.011559 | **0.055992** |
| 状态 JEPA（seed 11） | 0.001338 | 0.031962 | 0.120365 |

**JEPA 好于两个简单物理基线，但差于学到的线性残差模型。** 不应因模型名称
先进就替换更好的方法。本轮没有证明 JEPA 架构本身带来收益；还缺无 JEPA
监督 MLP、无正则等消融。潜变量平均标准差约 0.71–0.75，只是一个诊断量，
不能单独证明表征质量或排除部分维度塌缩。

`artifacts/runs/seed11_single/`、`seed23_single/`、`seed37_single/` 中分别有：

- `report.json`：完整指标、数据参数/哈希、权重哈希、验证选择和环境。
- `example_request.json`：完整输入，包含历史与候选动作。
- `test_predictions.json`：112 个测试窗口的完整输入、预测和模拟真值。
- `model.json`：本地数值权重，不使用可执行的 pickle。

种子 11 又完整复跑一次，位于 `seed11_single_repeat/`。两次权重文件与
`test_predictions.json` 的 SHA-256 完全相同；只比较这些确定性产物，不要求
运行耗时相同。此复现仅限同一环境，不宣称跨系统训练逐位相同。

## 验证与失败记录

10 项标准库单元测试通过：输入字段/时间/数值范围、NaN/Inf、共享 NED、拒绝
陈旧和 vehicle_local_ned、坐标符号、重复预测、非授权语义、数据分组、模型
形状、文件篡改/目录逃逸与跨架构 golden 数值容差。

训练 PyTorch 与纯 Python 导出推理最大数值差异（seed 11）：2.531e-6。
本机 10 步纯 Python 热推理 median 2.853 ms、p95 4.036 ms（100 次，另 10 次
预热）；不含文件加载、校验、进程启动，不能解释成端到端或板端延迟。

保留了失败目录，未覆盖或计为成功：

- `seed11/`：训练完成后在 NumPy/BLAS 基线评估时 OpenMP 重初始化冲突。
  改用原生 Python Cholesky 求解小型岭回归，不设置危险的重复库忽略开关。
- `seed11_cpu_noblas/`：异常退出，仅有权重、无完整报告，原因未确证。
- `seed11_complete/`：旧双线程配置完整通过，但其重复训练
  `seed11_repeat/` 出现 Windows native access violation，堆栈在 PyTorch
  激活函数；`artifacts/seed11_repeat.log` 保存了异常。
- 最终单线程的三种子和 seed 11 重复轮均完整退出 0。这个配置规避了本轮
  故障，但没有证明旧环境的底层库问题已经根治。

没有把模型结果自动改成正确答案，没有关用户应用，没有启动真实任务。

## 可迁移包：已生成，未做板端验收

路径：`artifacts/bundles/state_jepa_v0_1/`，生成时约 202 KB，推理零第三方依赖，
需已有 Python >=3.10。包含权重、完整示例输入、golden 输出、11 个文件的
哈希清单、标准库推理代码与离线自测。整个目录复制后可运行：

同目录已生成 `worldlab-offline-state-jepa-v0.1.zip`（65,183 字节），归档 SHA-256：
`DA125F65B315AB4E4012965FD6CCC853694A2BA71A5A34316E5B0E155B5ED13C`。
解压后进入其中的 `state_jepa_v0_1` 目录；归档不含训练库或 Python 安装器。

```text
cd <迁移包目录>
python -S offline_selftest.py
python -S -m worldlab.cli infer --model model.json --input example_request.json
python -S -m worldlab.cli inventory
```

本机 5 次独立 `python -S` 冷启动自测通过，不加载 Torch/NumPy或 site-packages。
自测先实证 socket 创建会被审计钩子拒绝，再完成推理、文件哈希与 golden
检查；元数据须精确匹配，预测数值固定绝对容差 1e-5。
**这是 Python 网络 API 阻断测试，不是操作系统断网或 Orin 试验。**
哈希检测损坏，不构成发布者签名；迁移包及其校验来源仍须可信。

目标为用户图示 Jetson AGX Orin 32GB。当前不知道 JetPack/Ubuntu/Python、功耗
模式和冷却，没有板卡访问权限。Python 版本若低于 3.10，不能直接视作兼容。
板端应断网、清空模型缓存、校验包、跑 5 次冷启动，记录内存/延迟/温度/功耗。
这个包可做无 GPU 的算法自测；没有 TensorRT 引擎、视觉编码器或机体模型。

## 接下来，分开验收两条路线

1. **状态动力学研究**：增加监督残差 MLP 与 JEPA 消融；再引入姿态/角速度/
   推力及明确的物理参数外推测试。冻结新的未见测试集；本轮看过的测试结果
   不再作为后续调参的未见验收集。只有模型优于强基线或表现出其他实证收益，
   才讨论作为上层候选轨迹评分器，仍不直接控飞控。
2. **视觉路线**：先评估 [LeWorldModel](https://github.com/lucas-maes/le-wm)
   约 15M 的独立离线原型；其已有操控/导航环境权重并不是无人机专用权重。
   视频表征对照考虑 [V-JEPA 2.1](https://github.com/facebookresearch/vjepa2)
   的 80M ViT-B。先锁定代码版本、许可证、预处理、帧窗、权重哈希和离线依赖，
   再做本机加载与目标板评测；本轮没有下载或运行这两类视觉权重。
3. [SkyJEPA 官方仓库](https://github.com/arplaboratory/SkyJEPA) 当前说明训练/
   评估/部署源码及预训练模型尚待发布；不将本原型冒称官方复现。
4. Orin 加速需要确认 JetPack/TensorRT，ONNX 导出与板端构建引擎单独验收。
   本轮不复制 Windows wheels 或桌面 TensorRT 引擎到 ARM64，不变更飞控。

无需为这个 4,491 参数实验租服务器。是否租 GPU 做视觉训练取决于后续实测
显存/内存、数据规模和预算，不能依据图上的 INT8 TOPS 直接推出模型帧率。

本轮所有新成果都只在该算法 worktree 下；运行数据/权重/迁移包被本模块
`.gitignore` 忽略，不会随源码提交。离线包需通过受控介质另行交付。
