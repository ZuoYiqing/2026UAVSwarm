## 固定数据与指标

旧集 9 条、8 条可评分语义；新集 18 条、17 条可评分语义。未知地点因现有候选 schema 不能表达空 bindings，
仅评分是否拒绝，不能把被 schema 迫出的候选当成公平的未知目标理解评分。
新集在任何模型作答之前冻结：`grounding_challenge_v0_1.json`，规范化哈希
`a75fb3e4143cf52586270bb53256bb2d74fa5398d9a0839c18ac53e2ccc565ba`。
包含三个新区域、六种访问排列、别名、否定、未知目标、巡检和背景地标；有 11 条预期可接受。
selective_v2 仍是此前在旧集上开发的提示词，本轮不改提示词、答案、校验器或基线算法。
这是前瞻性合成挑战集，不是第三方盲测，也不能代表实际任务分布。

“候选语义匹配”仅测意图类型及有序目标 ID，**不包含 matched_text 证据引用正确性**。
“接受一致”仅测 accepted 布尔值与标注一致，**不等于任务正确率**；必须同时报告错误放行。
ground-model 的节点分配仍是规则基线，不是模型的多机调度成绩。

为检查重复性，计划另跑两次；新进程中的第一轮约 5.34 秒就失败：模型虚构 TASK-4 至 TASK-13，

## 资源、边界与下一步

Mini 所有请求 GPU 总占用点样最大 758 MiB，最高 63°C，主机可用内存最小 3,450,656 KiB（约 3.29 GiB）；
Qwen 新集对应为 688 MiB、56°C、4,770,848 KiB。不是模型独占显存或可靠瞬时峰值。
Qwen 新集整轮约 12.86–13.53 秒；Mini 新集约 85.21–86.95 秒，主要耗在截断输出。
不能用只统计完整响应的 Mini 延迟中位数来宣称更快，失败成本必须计入。
没有触发 RAM/温度保护；所有本轮模型服务已停止，不关闭用户程序。

验证：45/45 离线单元测试、40/40 框架案例通过；权重未纳入 Git，真实命令发送数为 0。
机器可继续做这些小模型推理，目前无需为此租服务器；训练/微调及板端移植尚未实施。
Orin 与昇腾仍需具体型号、内存、软件栈；不能把 Windows CUDA 实测当成 ARM/CANN 部署证据。
