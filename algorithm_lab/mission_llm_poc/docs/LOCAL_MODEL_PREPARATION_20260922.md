## 可重复命令

在本模块目录使用PowerShell 7；不要在其他工作区或系统Python环境安装模型框架。

```powershell
# 准备：会访问制品源；已有正确文件只校验，不重下
./scripts/prepare_local_artifacts.ps1

# 校验、解压、检查引擎/GPU；不加载模型
./scripts/start_local_engine.ps1 -CheckOnly

# 无网络、无模型加载的下载器测试
./tests/test_prepare_artifacts.ps1

# 腾出内存并确认继续之后才执行
./scripts/start_local_engine.ps1
# 使用返回的launch.json执行单请求；结束后默认关闭模型服务
./scripts/run_local_smoke.ps1 -LaunchRecord '<D盘launch.json绝对路径>'
```

下载脚本不会自动下载许可证；当前本机许可已保存。
把完整artifacts目录转移到新设备前，仍须核对许可、平台兼容性和文件清单。
启动脚本只读本地制品，缺失或哈希不符就失败，不自动联网补齐。
